# RIRE Homepage Redesign

GitHub Pages向けの静的サイトです。

## ファイル
- `index.html` — リニューアル版トップページ
- `product.html` — MTG VITAL LIFE 商品ページ
- `style.css` — デザイン・レスポンシブCSS
- `script.js` — ヘッダー、モバイルメニュー、商品モーダル
- `assets/vital-life-catalog.jpg` — 今回いただいたVITAL LIFE写真

## 公開方法
現在のGitHub Pagesリポジトリのファイルを、このフォルダのファイルで置き換えてください。
`assets/vital-life-catalog.jpg` も同じ構成でアップロードしてください。

## 最終調整が必要な箇所
1. ACCESSの住所・営業時間
2. 予約用メールアドレス
3. Instagram / LINE URL
4. MTG商品の正式な価格・商品説明・購入方法
5. 必要なら商品写真を追加

※商品説明は、今回いただいた冊子写真から確認できる範囲をベースにした仮テキストです。公開前にMTGの公式資料・販売条件に合わせて確認してください。
