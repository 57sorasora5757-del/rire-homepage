# RIRE homepage redesign

GitHub Pages用のRIREリニューアルサイトです。

## VITAL LIFE商品ページ
`product.html` は `product-data.js` の商品データからカードを自動生成します。検索・カテゴリ絞り込み・商品詳細モーダル・ReFa公式商品ページへのリンクに対応しています。

ReFaの商品情報は公式サイトを参照しています。静的なGitHub PagesではReFa公式サイトの情報をリアルタイム取得するのではなく、商品データを更新する方式にしています。公式ページへのリンクから最新情報を確認できます。

## GitHub Pages
`index.html` を公開ルートに置き、Pagesを `main` / `/ (root)` に設定してください。
